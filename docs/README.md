# MDAC 项目展示站

独立静态官网，对应应用 v0.5.0。双击 `index.html` 即可本地查看；无需启动制谱工作台、构建前端或配置 API。正式地址：https://mdac.zakee.fun/ 。

GitHub Pages 从 `main` 分支的 `/docs` 发布。后续直接修改本目录并推送 `main`；保持 `CNAME` 中的域名和 `.nojekyll`。

页面顺序：下载音源与导入 → 歌曲裁剪 → 歌曲信息与场景 → 可选 API → 封面 → 可选 BPM → 自动制谱与定级 → 导出到游戏 → 下载。

采用用户指定 `project-showcase-site` 布局：居中图文、左右交替、横向翻页、无自动播放及底部导航；末页停止，品牌和末页“返回首页”可回到起点。支持点击、方向键、滚轮、触屏滑动、章节 hash 与减少动态效果偏好。
