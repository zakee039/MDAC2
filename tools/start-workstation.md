# 本机工作台

推荐入口：双击 `E:/project/MDAC2/start.bat`。它只构建并启动 MDAC2，访问地址显示在启动终端；请保持该窗口开启。默认端口被占用时运行 `./start.bat --port 8001`。首次环境准备仍按下方步骤执行。

在工程根目录执行：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-api.lock -r requirements-jobs.lock
cd web
npm.cmd ci
npm.cmd run build
cd ..
.venv/Scripts/python.exe -m mdac2.server --root E:/project/MDAC2
```

打开终端显示的本机地址即可使用，无需口令。默认仅监听127.0.0.1:8000，保留本机Host/Origin和跨站请求限制。服务需要 tools/audio-decoder.md 记录的本地 FFmpeg。

## 当前V3自动流程

1. 打开默认进入新建导入页。支持NCM/MP3/FLAC/WAV/OGG/M4A/AAC/OPUS/WMA/AIFF/ALAC/APE和MP4/MOV/MKV/WebM/AVI/WMV/FLV/MPEG/TS等音视频，最大256MB、音轨10分钟；自动提取第一音轨转44.1kHz双声道float32 WAV，原文件保存在项目内，最终试玩包使用OGG。已有项目重新导入时先保存未确认信息为草稿和封面裁剪，再创建独立项目，不覆盖旧结果。
2. 右上角「设置」→LLM配置：下拉选择“新建”清空表单，可选常见厂家预设，填写协议、完整Base URL（不会自动补/v1）、密钥、模型和代理，底部填写保存名称。测试仅检查当前草稿，不保存；保存新增或更新该配置；上方歌曲场景识别与封面生成独立选择实际使用的配置。下拉选择已有配置仅载入编辑，不切换用途，可修改后保存或删除。旧单配置自动保留为“默认配置”，已有密钥留空表示保持；密钥通过Windows DPAPI加密，不回显。代理地址可选，支持无认证HTTP/HTTPS代理（例如http://127.0.0.1:7890），留空强制直连，不读取环境代理；指定代理失败时不会回退直连。SOCKS和带账号代理暂不支持。
3. 上传/确认不调用模型；点击「用LLM填写」时LLM只接收歌曲名（文件名去扩展名），不发送音频、路径或工程数据。核对名称、音乐作者、场景、模型；创作者默认mikee。Miku与东方对应scene_10/scene_08；其他由LLM提出场景，不确定回默认。可手动修改全部信息。
4. 默认V3，V2是显式历史复现。开始制谱，保留每次尝试；有效缓存复用、失败/取消可重试、服务中断需重试，排队任务重新启动后继续。最长单任务3小时。
5. 制谱完成后点击“下一步 · 制作试玩包”，自动打包并进入导出页，无需再点构建。完成后下载，或点击「放入Custom_Albums」，首次点击弹出目录选择器，选择后持久保存，重启不需重选；可在设置中更换。下载和交付统一命名为 `[制谱人]-歌曲名.mdm`。同名不同内容拒绝覆盖，可修改曲名后重新生成。

GPU计算使用 `tools/.deps/pretraining-py313/Scripts/python.exe`，需当前冻结V2/V3权重及固定人声分离器。首次新歌分轨较慢，已完成缓存下次复用；不启动训练。开场提示通过map2.talk写入包，实际游戏显示待验收。

项目登记在chart/state.sqlite，原音频/尝试/缓存在chart/studio；LLM配置单独在chart/llm-settings.json（密钥密文）。关闭服务后再使用原工作区备份命令；备份包含新项目文件和引用的外部音频缓存，不含LLM密钥，恢复自动调整路径。勿只复制SQLite文件。

旧手工工作台的源码和API保留，但新首页不再将其作为默认流程。完整契约、实测与限制见设计25。应用版本保持v0.1.0，未打新tag。


## 精简界面与封面（2026-10-18追加）

顶部左侧文件夹打开项目管理弹窗，直接显示全部项目，支持载入、搜索、永久删除；右上角“新建”保存当前草稿并返回导入页。删除直接移除所选本地项目文件夹和登记记录，没有“已删除”或恢复；运行中的项目不能删除。外部原素材、共享缓存和已交付包不受影响。顶部正中MDAC2，右侧设置包含中文/English/日本語和LLM。语言保存在chart/preferences.json；刷新后自动读取。

导入与确认信息不会自动调用模型。点击「用 LLM 填写」才请求歌名、作者、演唱者与场景建议，初音演唱优先Miku，东方作品优先幻想乡。封面可点「本地生成」制作文字封面，或点「LLM生成」按H风格与补充提示词生成；失败本地降级。保留原图、512×512圆形PNG及手动裁剪；也可上传JPG/PNG/WebP（8MB）。不检索现有封面。提示词允许具备联网能力的生图服务查阅歌曲背景网页，普通Images接口不保证联网。

旧自动项目可用 `.venv/Scripts/python.exe tools/migrate_studio_projects.py --source <旧runtime路径> --target E:/project/MDAC2/chart` 复制迁移，先停止旧服务及活动任务；原目录保留。当前已将上轮8010验收的三个项目复制进入chart。默认旧runtime没有自动项目；历史手工项目继续保留在旧runtime，未混成新自动项目。日后常用入口仍start.bat；8010当前也使用chart。


## NCM导入（2026-10-18）

“选择歌曲”可直接选.ncm（含大写.NCM）。本地还原MP3/FLAC后自动进入原有制谱流程，无需手动转换；原文件在项目中保留，失败会明确提示。已验证用户提供的3份真实NCM。旧环境需要用上面的requirements-api.lock安装命令补齐依赖；当前本机已安装。解码使用API的Python3.12环境，不修改GPU环境。不联网获取NCM封面，封面仍使用独立配置的H风格生成/本地文字降级。

自动制谱页可切换V2（10.5）／V3（9.5）；切换使旧生成结果失效，重新制谱后才导出。模型参数和后处理仍使用各自冻结版本。开场声明改为参考《放我出去》的底部文本框，0秒打开、4秒关闭；实际观感待实机确认。LLM预设用于填写协议和接口地址，模型名仍可编辑；切换厂家不会把之前密钥带过去。

确认信息页按基础信息、封面、BPM纵向排列。播放音乐时默认同步清脆鼓声，分别调整音乐/鼓声音量；BPM与整体偏移决定鼓点位置。手打延迟仅用于补偿点击测拍。开启BPM对齐后每拍12个位置（兼容二连、三连、四连），音符起点与长条终点强制吸附；未开启保持冻结模型原时间。变速歌曲的单一BPM拟合需人工核对。
