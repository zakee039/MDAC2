# 01 系统架构与工程框架

## 1. 架构选择

采用本地模块化单体：Vue 3 + TypeScript 界面、FastAPI 接口、Python 领域核心、独立计算进程、SQLite 索引与文件产物。延续旧项目技术栈以降低迁移成本，但不沿用巨型 App.vue/main.py 编排。

首期不引入 Redis/Celery，不提供公网服务。作业后端先对 SqliteHuey 做小规模验证，再决定采用它或最小自研实现；应用服务始终拥有工程修订、资源预算和产物发布，不由队列库接管业务真值。未来远程 worker 只能扩展作业后端，不能侵入领域契约。Python/Node 与依赖精确版本在环境冒烟后冻结到锁文件；本文不凭历史环境写死 CUDA 组合。

```text
Vue 页面 / 编辑器 / 音频播放
               ↓ DTO / HTTP / SSE
FastAPI routes：参数、认证、错误映射
               ↓
Application services：命令、工程修订、作业与依赖规划
        ├─ Domain：时间轴、谱面、编辑、复用、验证
        ├─ Ports：分析器、存储、导出器接口
        └─ Infrastructure：SQLite、文件、worker、模型适配
                                      ↓
                       隔离计算进程：音频分析 / 推理 / 训练
```

领域层不能 import FastAPI、Vue、torch 或特定分析库；领域模型以标准 Python 数据结构与显式校验表达。数值音频算法依赖放在独立 analysis 包。接口 DTO 与核心对象显式转换，禁止把前端任意字典贯穿全部层。

## 3. 模块边界

| 模块 | 拥有 | 禁止负责 |
|---|---|---|
| TimingProvider | beat/downbeat 观测与来源 | 排键、强制补点 |
| TimingDeriver | 候选、拍号解释、时间映射拟合 | 将一致性分数称作真实概率 |
| StemProvider | 分轨及质量/变换记录 | 改谱面时间轴 |
| SimilarityProvider | 对应候选、相似证据、对齐映射 | 覆盖谱面 |
| OnsetPolicy | 声学候选的选留和密度 | 伪造强制覆盖率 |
| Arrangement | 物理地/空轨掩码 | 改变采音时间 |
| Semantics | accent、hold 等音符语义 | 修改权威时间轴 |
| ChartValidator | 错误和警告 | 不留记录地修谱 |
| Optimizer | 显式提出或应用有记录的编辑 | 写入上游原始结果 |
| Exporter | 确定性映射与资源封装 | 重新分析 BPM |

## 4. 计算与资源

API 进程只做短事务。音频转码、分轨和推理进入 worker；训练与制谱分开作业类型。默认同一 GPU 只跑一个重作业，避免训练抢占预览/制谱显存；CPU 并发按配置限额，不能为每个 HTTP 请求无限启动进程。

每个 worker 有超时、取消、进程退出状态和日志；不可中断的库调用通过进程隔离终止。推理缓存可复用，但失效模型不热替换正在运行的任务。OOM 返回明确错误和可选低资源重试配置，新参数形成新运行身份。

Huey 若通过验收，只处理排队/重试等通用功能；运行中取消由 MDAC 管理的隔离子进程承担。不能将 revoke 当作终止 native 推理，也不承诺队列“恰好执行一次”。详见 [组件验证](10-开源组件选型与验证.md)。

## 4.1 开源与自研分工

BeatThis 负责节拍观测，librosa 负责相似矩阵/对齐基础运算，mir_eval 负责标准音乐指标，wavesurfer.js 负责波形与区域 UI。领域层通过 ports/DTO 使用结果，不导入这些具体库。采音取舍、难度、地空/Gemini、人工编辑保护、可玩性与游戏导出仍由 MDAC 自研。

audio-separator 是多模型分轨接入候选；它的库版本、实际后端、checkpoint 与有效推理参数都必须写入 producer 身份。不能只记包装器名。All-In-One、Basic Pitch、OR-Tools 不是首版必需依赖。

## 5. 本地安全与分发

默认仅监听 loopback。检查 Host/Origin，并使用安装级会话令牌保护写接口；CORS 不是认证。所有资源按 ID 访问，禁止客户端提交任意本机路径。上传限制字节数、解码时长与资源预算，流式落盘；解码器失败不留下可用音频标记。

模型只从受管理注册表加载，检查哈希；不把任意不可信 pickle 权重视为安全数据。外部依赖按能力独立安装。下载由明确操作触发，不在制谱请求里隐式联网。代码、权重、音频的许可分别登记。
