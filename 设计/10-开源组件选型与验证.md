# 10 开源组件选型与验证

更新：2026-09-15。状态：设计选型，不代表已经安装、实测或完成许可审查。0.2 的原则是通用能力复用，音乐业务和状态一致性自研。

## 1. 决策矩阵

| 组件 | 决策级别 | 负责的 point | MDAC 仍需承担 |
|---|---|---|---|
| BeatThis | 首版复用方向 | beat/downbeat 观测，主/小模型对比 | 拍号解释、时基拟合、复核与本地权重管理 |
| librosa | 首版复用方向 | 特征、自相似矩阵、路径增强、受限 DTW | 相似判定、拒绝条件、段落成组和谱面复用 |
| mir_eval | 首版复用方向 | 标准 beat/onset/segment 指标 | 数据资格、防泄漏、难度/禁手/人工指标 |
| wavesurfer.js | 首版复用方向 | 波形、Regions、Timeline、Minimap | Transport、拍格、Note 编辑、revision |
| Demucs / RoFormer | 同集评测后选择 | 四轨或人声/伴奏专用分离 | 能力契约、有效运行身份、对齐与下游收益 |
| audio-separator | 接入包装候选 | 多种分轨模型统一调用 | 禁隐式下载、实际后端/精度/权重来源登记 |
| SqliteHuey | 小实验后决定 | 无 Redis 的本地排队、重试、优先级 | 运行中取消、lease、工程状态、outbox、幂等 |
| All-In-One | 后续可选 | 大段边界、功能标签、结构 embedding | 精确段对确认；两个 chorus 不代表可复制 |
| Basic Pitch | 后续可选 | 单纯旋律轨的音符起止证据 | 采音取舍、Hold 合理性、人声音节区别 |
| OR-Tools CP-SAT | 后续局部实验 | 固定落点下约束修复 | 约束正确性、音乐质量、超时/无解处理 |

首版复用方向表示实现优先采用其成熟功能，仍须可安装、API 契约和小样本测试；失败可退回显式规则基线。未选中的候选不安装到核心环境，不同时维护多个生产实现。

## 2. 组件验证包

### E1 BeatThis

同一合法短曲、固定规范化音频对比主/小模型，记录 beat/downbeat、局部错位、耗时、峰值资源；缺权重应快速失败且不联网。保留可选 logits，但不称其为校准概率。验证预训练集重合风险，不能照搬上游论文结果。

### E2 分轨

选择具有合法使用条件的一种 Demucs 和一种人声专用 RoFormer checkpoint。使用器乐、人声密集、弱瞬态样例，记录对齐/长度、瞬态变化、人工听检、采音候选收益和资源；不以包装库输出的模型 SDR 排名直接决策。GPU 不具备时标记未测，不凭 CPU fake 结论选择生产模型。

### E3 相似段

在固定人工段对上比较旧 Mel 基线与 Chroma/起音包络/Mel 融合。报告真实重复、相似伴奏不同人声、静音、变体段和不同速度的表现。DTW 设置约束、覆盖率/代价拒绝面，包含不应匹配的反例。矩阵规模与峰值内存列入验收。

### E4 SqliteHuey

仅做隔离原型：Windows consumer 启停、排队优先级、失败重试、重复投递、进程崩溃、运行中取消。证明队列数据库和业务数据库之间可通过 outbox 去重协调。revoke 仅用于未开始任务；强取消由独立计算子进程负责。原型不自动迁入生产；记录 adopt/reject 及适配成本后仅保留一种正式 backend。

### E5 wavesurfer

wrapper 将播放命令与秒坐标事件接入统一 Transport；验证多视图 seek、循环、卸载重建、预计算波形与长音频。只能一个音源驱动当前传输时间，不让 Regions 回调直接写项目状态；通过 command 提交边界编辑。

## 3. 非首发实验的放行条件

All-In-One：先验证 Windows 依赖构建，再证明减少段对漏检/人工负担；不能借它的第二套 beat 替换当前时间轴。

Basic Pitch：只对适合的分离旋律输入测 Hold 头尾候选；若 MIDI 转录增加重复/无意义落点则不启用。

CP-SAT：只处理有限窗口的明确冲突，不移动锁定事件；返回 feasible/infeasible/timeout，不承诺最优解或好玩。与简单规则/动态规划比较收益后决定。

## 4. 许可与运行身份

代码许可、权重许可、训练素材权限分别记录；README 上的 MIT 标识不能代替每个第三方 checkpoint 的授权。模型清单记录下载来源、版本/hash、允许用途和依赖。对包装器运行时 fallback/精度降级记录实际参数并重新计算身份，不可仅保存用户请求值。

## 5. 官方来源（前轮已查，实施时再次核对所锁版本）

- [BeatThis](https://github.com/CPJKU/beat_this)：beat/downbeat、帧级输出、主/小模型、预训练数据重合提示；默认推理可能下载权重，MDAC 必须显式管理本地路径。
- [librosa path_enhance](https://librosa.org/doc/latest/generated/librosa.segment.path_enhance.html)：自/交叉相似矩阵的多角度连续路径增强。
- [librosa DTW](https://librosa.org/doc/0.11.0/generated/librosa.sequence.dtw.html)：子序列与全局路径约束，不包含 MDAC 的匹配放行策略。
- [mir_eval API](https://mir-eval.readthedocs.io/latest/api/index.html)：标准音乐评测接口。
- [wavesurfer.js](https://wavesurfer.xyz/)：波形、区域与导航插件。
- [audio-separator](https://github.com/nomadkaraoke/python-audio-separator)：多架构/多输出轨道支持，具体模型质量需同集比较。
- [Huey guide](https://huey.readthedocs.io/en/latest/guide.html)：SQLite 后端与未开始任务撤销；不等于运行中强制终止。
- [All-In-One](https://github.com/mir-aidj/all-in-one)：结构标签/边界，Windows NATTEN 构建要求需验证。
- [Basic Pitch](https://github.com/spotify/basic-pitch)：音频转音符/MIDI，官方说明更适合一次一种乐器。
- [OR-Tools CP-SAT](https://developers.google.com/optimization/cp/cp_solver)：整数约束与求解状态。

上述资料支持组件能力，不能支持“在 MDAC 上效果更好”的结论；后者必须来自 E1～E5 和业务验收。
