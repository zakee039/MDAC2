# 人声前瞻与长条网格对齐 r2

2026-10-17。用户已明确固定 BPM 240、每拍 50 格、5ms 自动吸附。本轮实现、22 验证、两曲预测与独立试玩包均完成；工程检查通过。随后用户反馈“这版体感很不错”，明确将本版本定为正式 **R1**，登记关系见[21-V系列与R系列版本规范](21-V系列与R系列版本规范.md)。下文评价、产物与当时待评记录保留，最新反馈在 recipes/R1/manifest.json 单独登记；未推断逐首或所有歌曲验收。发行 v2 与人声实验 r1 原样保留，桌面默认生成流程未替换。

## 时间契约

本次 BPM 只用于固定存储时基，**没有重新估计歌曲 BPM、拍位或节拍相位**。零点为音频 0 秒，240 BPM = 每拍 250ms；每拍 50 格，每个四拍小节 1 秒、200 格，间隔 5ms。包内 `info.json` 与 `map2.bms` 都写 240。每条音符通道数据为 200 个双字符格，音乐触发通道单独保留。旧包 BPM 120、每个两秒小节 2000 格的 1ms 编码不变。

采音仍在 10ms 声学帧上输出局部峰及帧内偏移；推理得到绝对时间后统一量化。采音特征步长、事件定位、最终存储网格是不同概念。1ms 精度本身不是已证实的卡顿原因，5ms 吸附也不保证改善手感。

所有点击及长条头尾就近吸附到 5ms，半格向后取整；原来同一时刻的物件成组移动。一般位移不超过 2.5ms。若取整把原来合法的同轨点击变成 20ms 冲突，可在相邻格修复，最多偏移 7.5ms；仍非法则失败，不丢键、不变类型。此次 24 曲均未触发额外修复，最大实际取整位移 2ms。导出拒绝离格事件，不能暗中二次量化。

## 一秒人声前瞻

新模块 `vocal_priority_r2.py` 复用固定分离缓存和冻结神经网络，属于推理选择层，没有重新训练。活动判定与起音判定分开：

- 观察未来一秒的分离人声能量、频谱占用及片段持续性；至少 25% 的未来覆盖、片段至少 80ms，可连接内部至多 80ms 的短停顿。曲尾按可用未来长度计算。这些是探索性规则，不是人声真值分类器。
- 频谱占用至少 12.5%，至少两个频带有证据；弱且与伴奏近乎相同的分离信号按残留处理。强乐器泄漏仍可能误触发，弱人声也可能被拒绝。
- 从证据片段的实际起点生效，最后活动结束即退出，不再保持两秒，也不在未来开始唱之前提前切换。
- 人声区模型候选门限 0.12→0.08，起音支持门限 0.22→0.16，人声候选最小帧间距 80→60ms。只从模型局部峰选择，仍要求 ±40ms 内的人声起音证据；不是对音量峰逐帧打点。
- 不确定区恢复原 v2 的 0.3 候选。它是人声＋伴奏联合采音结果，不是原曲专用网络；当前尚无原曲专用采音模型。高潮候选也受人声证据门控，不补回被排除的乐器点。

普通区的内部字段 `accompaniment_selected` 表示回退候选数，并不证明候选来自伴奏。两曲人声模式较 r1 明显缩短：琵琶行 104.8→39.9 秒，Snow 196.26→119.99 秒；部分真实人声可能被新规则判为不确定，不能把回退得到的召回提升说成人声识别已改善。

## 长条对齐与后处理顺序

顺序为：新采音选择 → 冻结排键整曲推理 → 门控高强度候选 → 原连续点击编排 → 5ms 吸附 → 长条端点对齐 → 相似段镜像 → 只读规则检查和导出。

**r2 不调用旧 250ms 单向补尾。**在约 100ms 的候选关联范围内：

1. 长条头／尾遇同轨或异轨轻击、重击、Gemini，以已经落格的 note 为锚点，允许延长或缩短；不移动锚点。
2. 未被 note 锚定的长条端点，覆盖同起、同收、一开一关，取端点组平均值再吸附 5ms。例如 300ms 与 400ms 合到 350ms。
3. 保留原有共同头尾关系，禁止链式跨越原始 100ms 跨度，禁止把同一长条头尾合并；长条最短 30ms，保留长按＋单个点击例外、特重排他和同轨不重叠。
4. 相似段镜像仍是最后一次编辑，只改合法轨道，不改变已经对齐的时间。

22 验证共调整 533 根长条：325 延长、206 缩短、2 根整体平移且时长不变；13,150 个时间位置量化。琵琶行调整 17 根（11 延、6 缩）；Snow 调整 69 根（45 延、24 缩）。所有生成事件通过规则及 BMS 回读，但合法性不等于音乐表达正确。

## 同口径结果与取舍

r2 地面/天空 F1 为 44.27%/42.08%；轻击 30.77%、重击 7.80%、特重 23.53%、Gemini 13.62%、长条头 9.08%、长条尾 4.77%。特重仅命中 4 个、误报 9 个，不能因稀有类宏指标上涨宣称整体排键已解决。r2 对 r1 漏点减少，但误点增多，长条指标也有退步。

单因素前瞻与门限对照见 `onset-ablation.json`：仅换前瞻、保持旧门限，原始采音 F1 76.72%、召回 79.73%；完整降门限 r2 F1 76.20%、召回 82.63%。此处为排键前、无掩码去齿轮起点口径，不能与上表混算。r2 保留预先指定的偏召回探索配置，不称最佳 F1，也没有用两首用户歌曲选参。

同一生成谱的量化/对齐消融见 `grid-diagnostics.json`：量化前采音 F1 76.409% → 仅量化 76.375% → 对齐后 76.317%；长条联合 F1 从 2.897% 降至 2.504%。因此本轮结构对齐没有改善参考谱准确率；是否改善手感仍需实机对照。
