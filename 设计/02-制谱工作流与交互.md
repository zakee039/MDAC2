# 02 制谱工作流与交互

## 1. 用户流程与后台依赖分离

页面保留七阶段心智模型，但“当前浏览页”不代表后端完成进度。分轨/相似建议可以在依赖就绪后异步计算，不能通过跳页伪造产物。

| 阶段 | 用户动作 | 成功条件 |
|---|---|---|
| 1 导入 | 选音频、新建或打开工程 | 原始文件校验、解码成功、源资产冻结 |
| 2 时间与信息 | 听节拍、校正时基、封面/元数据 | 当前 TimingRevision 通过结构校验和复核门槛 |
| 3 采音 | 选择难度、音轨偏好、试听与编辑落点 | 候选与选留可解释，编辑修订已保存 |
| 4 排键 | 地空与双键预览、局部修改 | 时间保持，轨道分配合法 |
| 5 音符语义 | 普通/重音/Hold 等修订 | 语义合法，长条范围可见 |
| 6 结构与优化 | 相似段确认、复用、优化 A/B | 每项变化可审阅，最终验证无阻断错误 |
| 7 导出 | 资源预检、构建、下载 | 当前修订指纹一致，BMS 回读及包校验通过 |

相似段建议的入口可提前在第 2 阶段出现，用来听检结构；其创作应用只作用于第 6 阶段明确选定的谱面版本。编辑元数据不触发昂贵模型重算。

## 2. 时间轴编辑

显示波形、脉冲、downbeat、小节编号、变速/变拍号边界、候选和残差。普通视图显示容易理解的节拍；高级视图显示 pulse unit、拍号分母和 quarter-BPM。

支持人工 tap（保存每次点击时刻与输入延迟设置）、局部拖动 beat、插入/删除 beat、标记 downbeat、倍/半网格、小节相位与拍号修正。每次修改生成草稿，先做校验再提交新时间修订；撤销/重做以编辑命令为单位。网格密度变化与音乐加速不是同一个命令。

低置信、复拍歧义和漂移须定位到片段，不以整首一个红色灯替代。用户可以拒绝自动候选，手动建立有效时间轴。人工确认保留算法分数，不把它们改成 1.0。

修改已有谱面的时间轴时，必须显示两种语义：保持音频位置（秒不变，重求 q）或保持音乐位置（q 不变，重求秒）。已有人工事件首次迁移默认先预览，不自动提交；用户选择写进 EditRecord。Hold 的头尾、相似段边界和锁定事件一起列入影响清单。不能只移动 Note 头不处理尾点，也不能未经同意跨时间轴重放旧补丁。

## 3. 采音与谱面编辑

候选层与最终选择层分开显示；候选显示时间、证据轨、强度/分数、量化误差和选留原因。最终事件支持增删移动、局部再生成和“锁定人工编辑”。再生成默认在新分支比较，不悄悄覆盖用户修改。

排键或语义推理首版保持事件 ID 与时间不变；需要增删落点时必须显式回到采音修订或产生可审阅的优化补丁，不能伪装为配色模型行为。

## 4. 预览一致性

音乐、节拍器、音符预览共用一个播放时钟，不用多个 timer 各自累积。基于音频上下文的播放位置计算画面，seek 后重建局部调度队列；测试暂停/恢复、循环、后台切回、倍速试听和蓝牙延迟补偿。

延迟补偿仅影响监听或显式校准，不改变原始音频及谱面时刻。导出音频裁剪后的坐标换算来自 AudioTransform，不能再次加原始 offset。音频资源通过 API Blob/Range 获取，不设置伪后缀文件路径中间件。

波形、区域、刻度和缩略导航优先封装 wavesurfer.js；节拍拍格与游戏谱面仍自行绘制。组件服从共享 Transport，不允许多个波形播放器分别驱动时钟。验收包含同一音频多视图 seek 与循环一致性；前端 wrapper 对领域层只暴露秒坐标事件。

## 5. 重算影响

| 修改 | 失效范围 |
|---|---|
| 音频内容/规范化策略 | 依赖该音频的全部分析与谱面 |
| 时间映射 | 节拍同步特征、相似对齐、采音及后续；纯分轨不失效 |
| 分轨模型 | 依赖音轨的分析、采音；纯混音检测可保留 |
| 难度/采音策略 | 采音到导出；通用时间与分轨保留 |
| 人工落点 | 排键、语义、结构应用、导出 |
| 轨道编辑 | 语义/验证及依赖轨道的下游 |
| 相似组确认或复用模式 | 结构应用到导出，不重做原始采音 |
| 封面、标题、作者 | 包资源/导出；不重算谱面 |
| 监听音量、语言、主题 | 不影响任何领域产物 |

以上为默认依赖图；实际失效由每个步骤声明的输入键计算，不硬编码成“步骤号之后全部删除”。

## 6. 异常、恢复和冲突

作业失败：保留上次成功产物与错误原因，不标为完成。关闭页面：后台任务按配置继续，重开从服务器恢复。后端重启：未完成作业进入 interrupted，不能自动宣告成功。

保存使用预期 revision；另一个窗口已修改则返回冲突，提供差异合并，不覆盖。旧版本可只读打开并导出历史快照，但必须明确选“导出历史修订”，不能通过默认导出冒充当前版本。

暂时放弃只改变列表状态，不删文件。删除进入回收站，显示引用与可恢复期限。导出成功不是工程进度归零；工程仍保留完整修订历史和最近导出记录。
