# 08 实施路线、验收与风险

## 1. 总体节奏

以可交付闭环分批，每批都有可观察结果。阶段完成条件是验收证据，不是目录数量、模型数量或“代码已写”。先实现单机产品，不在首批扩展云服务和训练平台。

## 2. 分批路线

| 阶段 | 交付 | 必须通过的验收 |
|---|---|---|
| M0 基线与环境 | 运行环境检查、历史资产清单、版本/备份方案、小型合法测试资源 | 明确可运行能力与缺项；空环境可按步骤复建；历史测试不冒充新验收 |
| M1 最小制谱闭环 | 工程、音频、手工时间轴、手工/规则落点、基础两轨与音符、预览、导出 | 一首合法短曲从导入到游戏加载；含撤销、保存重开、BMS 回读；不依赖新模型训练 |
| M2 时间分析闭环 | 真实 TimingProvider、推导、候选/人工编辑、单一时间映射 | 固定/变速、弱起、6/8 样例通过；自动失败仍能手工完成；有真实 provider 日志 |
| M3 音轨与辅助采音 | capability 驱动两轨/四轨接入、来源明确的伴奏、候选与选留分离、混音基线 | Demucs/RoFormer 同集小实验；对齐/失败恢复；休息保持；资源记录 |
| M4 相似段闭环 | librosa 自相似/受限对齐基线、A/B 试听、边界编辑、编排参考/镜像 | 人工段对与误报集；与旧 Mel 对照；空主段不清谱、重叠拒绝、人工锁保护 |
| M5 品质与规则 | 模型排键/语义可选接入、Hold、独立优化器、局部生成 | 与规则基线对比；每次规则修改可解释；边界冲突可复现 |
| M6 发布级验证 | 锁集、端到端与 A/B、历史 importer、备份恢复、发布包 | 07 文档 release policy 通过；20 首目标集和游戏验证；新目录恢复成功 |
| M7 研发平台 | 数据标注、训练、晋升、更多 provider | 数据防泄漏、真实候选冻结、明确晋升；不是首发前提 |

训练不应阻塞 M1-M4；相似度模型权重缺失也不应阻塞只读基线与人工分组。每个阶段都允许回到手工流程，但必须明确记录 manual/baseline 来源。

## 3. 第一批建议任务分解

1. 创建包与前端骨架，doctor 能检查解码器、Python、音频播放、可选模型。
2. 实现 AudioAsset、TimingRevision、ChartIR 最小契约与 golden fixture。
3. 完成工程 SQLite/文件发布协议、revision 冲突和恢复测试。
4. 实现手工时间轴与两轨编辑、统一播放时钟。
5. 隔离验证旧 BMS 映射和模板，形成新 exporter profile。
6. 接通导出预检、回读、MDM 和游戏导入验证。
7. 完成一次工程备份→新目录恢复→再导出，冻结 M1 基线。

具体施工不把一整个里程碑交给一次任务。以 [施工计划+日志](施工计划+日志.md) 的独立工作包执行；优先验证 wavesurfer wrapper 和队列后端边界，后续按依赖引入 BeatThis/librosa/mir_eval。All-In-One、Basic Pitch、OR-Tools 不进入首版关键路径。没有用户要求时不自动开启新任务、调度监控或重置额度。

## 4. 风险与应对

| 风险 | 应对 |
|---|---|
| 旧权重与后期代码不全 | 日志原文恢复单独保存来源；新设计不以完整恢复为前提 |
| MIR 依赖/设备不兼容 | 隔离环境与 adapter、固定版本、doctor、真实冒烟 |
| BMS 特殊对象语义不明 | 限制支持范围，真实模板和游戏测试，不猜测映射 |
| 时间轴过拟合/导出复杂度高 | 统一拟合策略与残差预算，简化需用户确认 |
| 相似复制损害目标细节 | 默认只读建议，编排与完整替换分开，显示 diff |
| 框架建设无限扩张 | M1 以实际可玩导出为硬闸门 |
| 数据/权重再次丢失 | 异故障域备份、哈希清单、恢复演练 |

## 5. 尚需用户或实测决定的事项

- 正式产品显示名使用 MDAC2 还是 MDAC 2.0；目录保持现有 MDAC2。
- 首发目标游戏加载器/版本和允许对象集合；实测前仅承诺基础 profile。
- 默认难度范围与示范歌曲，需使用有权处理的素材。
- 本机 GPU/内存预算及首选模型，先跑 doctor 和真实样例再冻结。
- 首期采用纯浏览器本地界面还是后续封装桌面壳；默认本地浏览器，不阻塞内核。
- 日常备份目标与远端仓库，未经明确授权不推送音频、源码或权重。

这些事项不妨碍开始纯本地、基础对象、手工可操作的 M1。影响破坏性迁移、外部发布或资源授权时必须先确认。

## 6. 每批完成记录模板

实施记录包含：目标、修改清单、契约变更、测试命令和结果、真实样例、资源用量、截图/回读/游戏证据、已知缺陷、回滚方式、备份位置。未运行的测试明确写未运行。新增设计决策同步 09 文档；不能将历史日志结论直接复制成当前成功报告。
