# 07 训练、评测与质量门槛

## 1. 两种正确性

工程正确性：契约、身份、缓存、事务、取消、回读、安全。音乐正确性：拍点、结构、选音、难度、可玩性。前者可由自动测试覆盖，后者必须有真实标注与人工听玩验证。107 个历史测试或高覆盖率不能代替新项目的业务验收。

## 2. 数据集与标签

分 train / validation / locked_test，以作品族先分组，再按规范化音频身份去重。先分歌曲再切窗口；同曲不同谱、翻唱/重混关系按明确 work_family 政策处理，人工处理不确定归属。

DatasetManifest 保存资产 hash、family、许可/使用范围、标注版本、难度、slice、数据角色。冻结后修改产生新版本。训练代码、特征 schema、模型配置、随机种子和依赖锁一起记录。

人工 timing reference 保存原始观测、修订血缘、标注人和复核状态。自动改名为 human_confirm 不得进入金标准；自动参考只允许做系统一致性实验并明确标注，不能汇报为准确率。

冻结前抽样二次复核并记录标注分歧；争议时间边界可给容差/不确定区间，不强制伪造唯一精确真值。谱面创作允许多个合理参考，未复现某位谱师的排键不能直接判错。Manifest 增加预训练语料重合风险（known_overlap/known_disjoint/unknown），未知不得当作已排除泄漏。

## 3. 分阶段指标

| 层 | 指标 |
|---|---|
| 时间 | beat/downbeat F1、相位错拍、速度 Acc1/Acc2、时间映射残差、拍号段与弱起边界 |
| 分轨 | 对齐偏移、长度、失真/串音抽查、输出完整性、耗时/峰值内存 |
| 采音 | 容差事件 P/R/F1、量化误差、真实休息保持、密度曲线、人声与器乐 slice |
| 排键/语义 | 分类/序列指标、双轨完整性、Hold 区间与尾点、实际禁手率 |
| 相似段 | 段对 P/R、边界/对齐误差、候选负担、人工接受率、复用后质量 |
| 完整谱面 | 可加载率、硬错误、峰值 NPS、人工修订量、匿名 A/B 偏好 |

历史 ±70ms beat 容差和 ±4% tempo 容差只作为 baseline profile；正式报告必须列出实际容差，至少提供更严格容差敏感性结果。Acc2 容忍倍半关系，不能掩盖 Acc1 低或小节起点错误。

beat/onset/segment 等标准指标直接封装 mir_eval，固定库版本、参数与参考预处理；旧自写指标仅用于历史复现，并标不同 profile，不能混合比较。MDAC 自研仅承担禁手、休息保持、人工修订量与复用质量等业务指标。不同运行输出标准指标适配器版本，避免算法未变而指标实现变化造成假提升。

缺失估计计入覆盖率；指标分别输出成功子集结果和全锁集失败计数，不能只报告成功样本平均分。分轨没有干净 reference 时不声称有客观分离质量分数。

## 4. 组件与端到端双基准

同一采音候选模型分别用人工合格 timing（oracle）和自动 timing（auto）评测，其他变量固定，揭示误差是模型自身还是上游时间轴引入。排键/语义同时在 gold onset 与自动 onset 上报告，不能只在完美输入上证明业务效果。

分 slice 至少覆盖固定/变速、3/4、6/8、高速、弱起、长前奏、器乐、人声密集。选择 epoch/阈值使用 validation；locked_test 只在候选冻结后运行，不能边看结果边调参后仍称独立测试。

## 5. 模型晋升

候选训练成功只代表产生有效 checkpoint，不代表生产晋升。晋升要求：契约/输入 schema 一致、完整模型身份、真实加载、冻结评测报告、基线对比、资源预算和明确批准。

首期 release policy：全部硬错误为零；同一固定集导出全部可回读；至少 20 首多类型歌曲做时间听检与制谱审阅，完整产品切换还要匿名 A/B 与游戏验证。数量是本设计目标，不是已完成事实；音乐改善阈值待基线测出后冻结，禁止临发布临时降低门槛。

20 首是初期覆盖门槛，不是统计充分性证明。每个 slice 报样本数、失败数、逐曲指标和人工修订耗时；小样本结果标不确定，适用时给 bootstrap 区间。优先补失败类型，不能只追加容易歌曲提高平均分。A/B 保持曲目/难度/监听条件一致，模型名隐藏；未完成游戏或人工验证时不得仅凭自动指标发布“效果更好”。

低于关键 slice 基线的模型默认拒绝晋升，即使整体平均变好；例外需书面说明影响、回滚条件与适用范围。生产别名更新原子化，已有工程仍引用旧模型明确版本。

## 6. 必测清单

- 时间：6/8 两种 pulse、变拍号、渐变速度、长尾静音、弱起、负音乐坐标、seek 后一致性。
- 数据：严格解析、数值边界、损坏 manifest、同尺寸篡改、全零恢复文件、丢失音轨。
- 编辑：撤销重做、旧批准失效、跨窗口冲突、局部再生成人工锁保护。
- 相似：空 primary、目标重叠、跨 tempo/meter、双轨同时事件、跨边界 Hold、仅编排点数不同。
- 作业：OOM、进程被杀、磁盘满、锁超时、重复点击、旧任务晚完成、SSE 断线恢复。
- 导出：弱起补位、时间偏移只应用一次、Gemini 配对、BMS 回读、资源校验、游戏加载。
- 安全：路径穿越、超大上传、外网写请求、无令牌写入、不可信模型、日志密钥泄漏。
- 灾备：数据库一致备份、缺资产提示、恢复到新目录、恢复后导出重放。

守卫类代码应做突变测试或故障注入：删校验/删锁/删清理后测试必须失败。对当前不可运行的集成环境标记 blocked/skipped 并列原因，不能用 fake 冒烟称为真实模型测试。
