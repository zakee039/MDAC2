# 制谱方案 R1

用户于 2026-10-17 反馈“这版体感很不错”，将当前方案定为 **R1**。当前组合是 **V2＋R1**；应用版本仍为 v0.1.0。

R1 的实验来源为 `vocal-grid-r2-20261017`，没有重新训练或更换 V2 权重。共享的连续点击编排、高强度候选、相似段镜像与安全规则继承 V2；新增一秒人声前瞻、较低的人声候选门限、固定240/每拍50格/5ms时间网格，并以约100ms长条端点对齐替换旧250ms单向补尾。相似段仍最后编辑。

`manifest.json` 冻结基线身份、参数、顺序、源码快照、评价来源及本轮用户反馈。`source/` 是来源文件快照，不能覆盖修改；不是独立安装的运行环境。实际入口与原目录名保留在清单中，运行前须核验绑定身份。权重继续引用 `models/v2/weights/`，R1没有额外神经权重。

两份 `_R1.mdm` 是获认可实验包的逐字节副本，包内保留原“人声前瞻r2 5ms”标题用于追溯。用户未逐曲说明反馈范围，不扩大为所有歌曲通过；原客观指标与局限保留。注册本身没有替换桌面默认生成流程。

版本边界和模块适用矩阵见 [V系列与R系列版本规范](../../设计/21-V系列与R系列版本规范.md)。正式大写 R1 不等于旧人声实验小写 r1，也不等于 V2 内的历史编排 r1.1。
