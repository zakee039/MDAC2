# MDAC · Muse Dash AI Chart

本地运行的 Muse Dash AI 制谱工具。从歌曲导入、自动采音与排键，到封面制作和 `.mdm` 试玩包导出，在一个工作台内完成。

**v0.3.0 · Windows · CPU 便携版 · 中文 / English / 日本語**

[个人主页](https://zakee.fun) · [爱发电 · 支持作者](https://ifdian.net/a/zakee/plan) · [版本记录](CHANGELOG.md)

源码部署需准备 Python 服务与推理环境、模型权重、FFmpeg，以及前端构建环境。当前启动入口为 Windows 的 `start.bat`；其他系统需要适配运行路径和系统相关功能。

## 主要功能

- **自动制谱**：从音频中采音、生成上下轨排键与长条，并执行冲突处理。
- **三种制谱选择**：人声优先 R2、综合 V2、综合 V3，默认使用综合 V3。
- **音视频导入**：支持 NCM、MP3、FLAC、WAV、M4A、MP4、MKV、WebM 等常见格式；NCM 在本地解码，视频提取第一音轨。
- **BPM 与节拍对齐**：支持自动测拍、手打测拍、BPM 与偏移调整、分段变速设置，以及可选的每拍十二等分强制对齐。
- **波形与试听**：选择制谱片段、缩放波形，同步播放节拍鼓声，分别调整音乐和鼓声音量。
- **歌曲信息与封面**：手动填写或调用 LLM 推荐歌曲信息和场景；支持内嵌封面、文字封面、上传图片、LLM 生图、历次封面切换和裁剪。
- **参考定级**：根据最终谱面给出本地参考等级，可手动修改并确认导出等级。
- **项目管理与导出**：本地保存项目，支持重新载入、重试任务，下载 `.mdm` 或直接放入 `Custom_Albums`。

## 使用步骤

### 1. 导入歌曲

选择音频或视频文件，导入后自动创建独立项目并保留原文件。支持最大 **256 MB、音轨时长不超过 10 分钟**的媒体。

### 2. 确认信息

填写歌曲名、作者、制谱人和游戏场景，选择封面与制谱区间。

如需节拍对齐，可以自动测拍或手打测拍，试听鼓点后调整 BPM 和偏移，再勾选「开启 BPM 强制对齐」。自动测拍和鼓声试听本身不会自动打开谱面对齐。

开启对齐后，点击与长条端点吸附到每拍十二等分网格，并进行拍内音符均匀化；关闭时保留原有毫秒时序。两种情况都会执行通用后处理和最终冲突检查。

### 3. 自动制谱

选择制谱模型并开始生成。首次处理歌曲需要进行分轨和特征分析，耗时会较长，CPU 模式尤其如此；后续任务会复用有效缓存。

生成完成后查看参考定级，按需要修改等级并点击「确认定级」。参考定级属于本地启发式估计，最终手感需要在游戏内试听、试玩。

### 4. 导出试玩包

点击「下一步 · 制作试玩包」，完成后下载，或使用「放入 Custom_Albums」交付到自定义曲包目录。首次交付时选择目录，之后会记住该位置，也可在设置中更换。

包名采用 `[难度]曲名 - 制谱人.mdm`，例如：

```text
[9.5]歌曲名 - mikee.mdm
```

同名但内容不同的交付包会追加 `v2`、`v3` 等后缀，保留已有版本。

## LLM 与封面设置

右上角「设置」中添加 API 配置，并分别为「歌曲场景识别」和「封面生成」选择服务。封面生成使用 OpenAI Images 兼容接口，歌曲信息使用聊天接口。

只有显式点击「用 LLM 填写」或「LLM 生成」才会调用相应服务。自动采音、排键和导出在本地执行，手动填写歌曲信息、使用本地封面即可完成制谱，无需配置在线 API。

封面生成使用歌曲名、作者和补充提示词；生成期间可继续调整项目，完成的图片会保存到发起请求的项目。联网查询歌曲背景的能力取决于所选服务。

## 项目与模型文件

项目、原始媒体、生成记录、缓存和设置默认保存在程序目录的 `chart/` 中。备份或迁移时请先停止服务，再复制整个 `chart/` 文件夹。API 密钥使用 Windows 系统加密，换电脑后可能需要重新填写。

项目管理中的删除为永久删除；已交付到外部目录的试玩包不受影响。

V1/V2/V3 制谱权重已通过 **Git LFS** 发布。源码部署请安装 Git LFS；已有克隆可在仓库根目录执行：

```powershell
git lfs install
git lfs pull
```

便携包已包含运行所需权重。下载 GitHub 的源码 ZIP 不保证获得完整的 LFS 权重；模型文件位置和校验信息见 [模型说明](models/README.md)。

## 常见问题

**启动后怎么打开？** 访问启动窗口显示的本机地址，不需要登录或口令。如果默认端口被占用，可在程序目录运行 `./start.bat --port 8001`。

**制谱失败后怎么办？** 可以直接重试，已有任务记录和有效缓存会保留。排查时查看对应项目任务目录中的 `worker.log` 和 `failure.txt`。

**可以直接在工作台手动编辑生成的音符吗？** 当前首页提供自动制谱流程，尚未接入生成后的逐音符编辑。
