本地 Muse Dash 辅助制谱工程。当前应用版本 **v0.1.0**，当前模型发行版本 **v1**。

- [版本说明](CHANGELOG.md)

- [工程设计与实施记录](设计/README.md)
- [前端开发](web/README.md)

v0.1.0固定2026-10-16用户确认的试玩基线。v1模型由独立采音模型和排键模型组成：人声/伴奏负责采音，原曲上下文及已生成历史负责排键。历史实验v6是排键组件的来源，保留原始实验编号便于追溯。

源码仓库不包含音频素材、社区谱、私有特征缓存、训练数据或权重。权重位置及SHA256由模型清单登记，缺失时不静默替换。Python包与前端版本均为0.1.0。

用户反馈《琵琶行》v6试玩体验不错，作为当前基线；此前客观分项仍有不足，详细结论见版本说明及模型清单。
