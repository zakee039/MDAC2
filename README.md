应用 v0.1.0 的既有 tag 保留。V2 复用原 V1 的独立采音和排键权重，并冻结原编排 r1.1；人声/伴奏负责采音，原曲上下文及已生成历史负责排键，历史训练实验 v6 是排键组件来源。

R1 是用户于2026-10-17认可的完整制谱方案，依赖 V2：沿用连续点击编排、高强度候选和相似段镜像，新增一秒人声前瞻、5ms固定时间网格，并用新长条端点对齐替换旧250ms补尾。R1没有新神经权重。这是历史R1方案；当前工作台默认V3，使用1ms存储、人声软偏好和严格长条区域避让，不自动叠加R1。

源码仓库不包含音频素材、社区谱、私有特征缓存、训练数据或权重。权重位置及SHA256由模型清单登记，缺失时不静默替换。Python包与前端版本均为0.2.0。

用户反馈当前R1来源版本“体感很不错”；此反馈与客观验证分项分别记录，不能扩大为每首歌曲均通过。旧V1/V2、实验、包与历史验收证据保留。

## 当前入口（2026-10-19）

双击本工程 `start.bat`，打开启动窗口显示的地址即可使用，无需口令。流程是 **导入歌曲 → 确认信息 → 自动制谱 → 导出**。导入即保存项目与原文件；右上角配置LLM后，点击「用 LLM 填写」才发送歌曲名并建议名称、音乐作者与场景；上传/确认均不自动调用模型。默认创作者mikee，自动制谱可选V3（9.5）或V2（10.5）。

完整《琵琶行》通过新流程生成、BMS往返和音乐编码检查，事件语义与冻结V3一致。导出带两行底部开场提示；「放入Custom_Albums」首次选择目录并跨重启保存，文件名为 `[制谱人]-歌曲名.mdm`。新提示按参考谱实现，实际观感待试玩确认。预览/手工微调未接入。真实LLM服务须用户配置，协议通过本地测试。


界面左上项目管理，居中MDAC，右上设置，主体四步流程。设置支持中英日三语与LLM；项目保存至根目录chart，删除会永久删除本地项目。确认信息分基础信息、封面、BPM三模块；封面可本地生成、手动调用LLM或上传裁剪。BPM支持自动/手打测拍、偏移修正和同步鼓声，开启后按每拍十二点（兼容二连、三连、四连）强制对齐。制谱完成点“下一步”直接制作试玩包。
