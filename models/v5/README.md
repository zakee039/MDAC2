# V5：独立长条与小 Boss 后处理

用户于 2026-10-21 指定，在 V4 基础上新增 V5。工作台可选，V4 仍是默认。应用 v0.5.0 起随便携包发布，用户已实机试玩并接受当前手感；`validation` 记录为 `accepted_by_user_2026-10-21` / `user_playtested`。

最新用户修订（v10）：Boss 准入只看合并后区间时长——<200ms 保留并统一成 100ms，200–2000ms 回退成密度丢弃（不生成 Boss，保留的可打 note 原位留下），>2000ms 原样。判据从 2N 换成秒，因为游戏按时长执行、2N 只是元数据。本曲 46 个区间 → 34 个 Boss（33 个 100ms + 1 个 2040ms），12 个降级、恢复 36 个 note，定级 11.8。流程身份 `studio-v5-boss-span-1ms-v10`。

上一版（v9）：人声句首不再保守——弱起区间改判"能量是否升上来"（`rise` ≥ 1.15 即接受，人声门槛 2%、总轨仍 12%），已有长条的头回拉到检测到的句首（单次最多 500ms，不越过同轨前一个事件）。本曲长条 67 → 68，8 个头被提前，被拒区间 9 → 4。流程身份 `studio-v5-vocal-head-1ms-v9`。

上一版（v8）：Boss 的击打数 2N 落在 **3–19** 的区间**不生成 Boss**，回退到丢弃模式（`_thin` 保下来的 note 留作普通 note，只丢多余）；2N ≥ 20 视为真 Boss 保留；2N ≤ 2 因 N ≥ 2 不可能出现。判据看合并后的 N，位置在 `dense_groups` 的合并循环里。本曲 47 个区间只成 2 个 Boss，45 个回退，恢复 63 个 note，目标定级 12.0 → 11.1。其余规则（80% 阈值、500ms 合并、长条 ±500ms 禁 Boss、滑块间距、长条内 2 倍、概率换轨、长条端点按普通 note）不变。流程身份 `studio-v5-boss-hit-band-1ms-v8`。

上一版（v7）：长条内部不再清空，落在长条时间窗内的 note 保留在原位，同轨 note 也合法；普通同轨最小间距由工作台滑块给出（75–175 ms，默认 125 ms），长条内部按 2 倍计算；长度 ≥500 ms 的长条按概率换轨，第 1 个对侧候选 50%、第 2 个必然，换完即结算，每个长条最多 1 个内部 note。长条头/尾按普通 note 参与同轨最小间距（不再使用 V4 的 500ms 尾部避让）。历史版本（初版、100%、50%、80%/100ms）快照存于 `revisions/`，对应原始包与验证结果保留。见设计27。

- 两份权重和先验引用 V3 原文件，不重训、不复制权重。
- 策略清单 `recipes/strategies/v5.json` 绑定 V4 父清单与继承源码、新增 V5 源码。
- 独立入口 `tools/studio_generate_v5.py`，支持制谱、参考定级、BMS 回读及 `.mdm` 导出。
- 间距由 `strategies/v5_spacing.py` 实现：`studio_timing_v4.py` 被 V4 清单逐字节绑定，不能原地修改，因此复用同一解析循环、只替换阈值；普通同轨用滑块值，同一长条内部用两倍值。
- 长条端点判定在 `strategies/v5_spacing.py` 的 `hold_edge_conflict`：只比同轨最小间距，不做额外净空。
- 概率换轨在 `strategies/v5_reroute.py`：只处理 ≥500 ms 的长条，只在落点满足两倍间距时换轨，换轨记录写入 `postprocess.json` 的 `hold_reroute`。
- 项目侧只保存设置（`spacing_ms`）与谱面归属的流程身份；流程变化只把谱面标记为需重制，音频、封面与歌曲信息不受影响。
- 旧 V2/V3/V4 清单与源码不变；不要运行旧的全量刷新脚本改写冻结身份。
- 初次开发登记工具 `tools/register_v5_strategy.py` 仅更新 V5，校验继承源码后登记。不用于未来修改已验收 V5；后续规则改变应新建版本。

本地工程验证不等于实机验收。小 Boss 的 `source_note_count=N`、`target_hits=2N` 只保存在 chart JSON 和 BMS 注释；加载器使用 `0G` 起止标记，未找到自定义击打次数字段。详见设计27。
